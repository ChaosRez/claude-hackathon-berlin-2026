Method

Every answer becomes a set of entities

1

Split into sentences

2

Split again at “; ” and “, but / however / although …”

3

Merge pieces that carry no meaning alone

4

Give each a type, a parent and any earlier points it repeats

12 types: claim, reason, elaboration, example, definition, opposing view, hedge, rebuttal, restatement, conclusion, advice, aside.

An entity is a nugget of value in the answer, not just a sentence. The codebook is in the repo so others can label the same way.
