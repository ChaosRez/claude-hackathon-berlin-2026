Decision · ADR 0001

Split once. Then vote five times.

The split is saved in each graph file and never redone.

Majority type per piece; the parent tree with the most votes.

Each piece keeps its vote share as a confidence.

Now the default: uv run python -m src.extract. One pass stays available with --approach one-pass.

Same accuracy as every other approach, clearly the most stable, about 3.5 times the cost of one call: roughly $34 for all 100 pairs. The tree step is a maximum spanning arborescence, written in plain Python in src/voting.py and tested against brute force and networkx.
